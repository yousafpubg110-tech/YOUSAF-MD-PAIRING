## <img src="https://readme-typing-svg.demolab.com?font=Orbitron&weight=900&size=16&pause=999999&color=00FFF7&vCenter=true&width=200&lines=✦+WHAT+IS+THIS%3F" alt=""/> &nbsp; What is YOUSAF-MD-PAIRING?

<div align="center">

> **YOUSAF-MD-PAIRING** is the official **WhatsApp Session Generator** for the [YOUSAF-MD](https://github.com/yousafpubg110-tech/YOUSAF-MD) bot system.
>
> Users visit the pairing website, enter their WhatsApp number, get an **8-digit pairing code**, link it in WhatsApp — and receive their **SESSION_ID** directly in their WhatsApp inbox. No QR code scanning required!

## <img src="https://readme-typing-svg.demolab.com?font=Orbitron&weight=900&size=16&pause=999999&color=ff00aa&vCenter=true&width=200&lines=✦+HOW+IT+WORKS" alt=""/> &nbsp; How It Works

<div align="center">

| Step | Action | Description |
|:----:|:------:|:-----------:|
| `01` | 🌐 **Visit Site** | Open the pairing website link |
| `02` | 📱 **Enter Number** | Type your WhatsApp number with country code |
| `03` | 🔑 **Get Code** | Click Generate — get 8-digit pairing code |
| `04` | 📲 **Link WhatsApp** | WhatsApp → Linked Devices → Link with Phone Number |
| `05` | ✅ **Get SESSION_ID** | SESSION_ID arrives in your WhatsApp inbox |
| `06` | 🚀 **Deploy Bot** | Paste SESSION_ID in YOUSAF-MD `.env` and deploy! |
